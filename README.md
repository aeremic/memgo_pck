# Memgo (Go Package)

Memgo is a Redis-like in-memory database written in Go. This package allows you to embed Memgo directly into your Go application to store and retrieve key-value data with native JSON support.

---

## Features

- Simple and lightweight
- Thread-safe
- Easy to embed in any Go application
